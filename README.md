# EdpEDiskAutoRun

Windows 下的 EdpEDisk 自动启动与托盘图标固定工具。

当前版本：`1.2.17`

## 功能

- 新盘符出现后自动查找并启动根目录下的 `EdpEDisk.exe`，包括被 Windows 识别为固定磁盘的 U 盘和移动 SSD。
- 将 EdpEDisk 托盘图标保持在任务栏可见区域。
- 监听托盘设置变化，检测 EdpEDisk 启动和任务栏重建；另有低频兜底检查，监听器全程后台运行。
- 不创建桌面快捷方式，也不扫描、监听或自动删除桌面快捷方式。
- 自动启动监听器安装在当前用户目录，不需要管理员权限。客户端需要提升权限时，由 Windows 正常显示 UAC；客户端密码窗口不会被隐藏。
- 常驻监听器改为原生 C++ 程序，不加载 .NET；安装/卸载窗口关闭后管理程序退出。
- 首次安装和版本升级前显示确认窗口，点击取消不会修改系统。
- 弹窗、EXE、任务栏和文件夹图标支持高 DPI、多分辨率显示。

## 使用

1. 直接运行 `EdpEDiskAutoRun-1.2.17.exe`，程序读取已安装文件的实际版本。
2. 未安装：显示“确认安装”；当前文件较新：显示“确认更新”，确认后替换旧版；版本相同：显示“确认卸载”。点击取消不修改安装。较旧版本不会覆盖较新版本。
3. 安装后程序会复制到：

   ```text
   %APPDATA%\EdpEDiskAutoRun\EdpEDiskAutoRun-1.2.17.exe
   ```

4. 安装文件内置原生后台组件，自动解压到同一目录的 `EdpEDiskAutoRun-Watcher-1.2.17.exe`。当前用户注册表启动项 `EdpEDiskAutoRun` 在登录后直接运行这个组件的 `--watch`，不会打开安装管理窗口，也不使用 Startup 快捷方式或新建计划任务。升级、卸载会清理旧版本的计划任务和启动项。
5. 同版本再次直接运行本 EXE 会显示卸载确认，无须添加参数。`--install` 可显式修复同版本安装，跳过首次确认但保留成功/失败提示；`--uninstall` 可显式卸载，仍需确认。

升级时使用带版本号的新文件名，并在切换登录启动项后清理旧版本，
不会覆盖仍在运行的旧版 EXE；遇到短暂文件占用会自动等待并重试。
同版本修复使用临时文件和原子替换，避免先删除原文件再写入。

## 安全边界

- 本工具使用 `asInvoker`，仅以当前用户权限运行。启动需要管理员权限的客户端时，短暂的启动助手调用 Windows Shell，不能绕过 UAC。
- 不修改 Defender、SmartScreen、组策略或安全例外。
- 不使用 PowerShell/VBS 作为运行时依赖。
- 托盘设置和自动播放设置均写入当前用户范围。
- 发布的 EXE 未使用受信任代码签名证书签名；企业策略可能阻止未签名程序。

## 1.2.17 更新

- 根据版本区分首次安装、覆盖更新和同版本卸载，窗口标题、EXE 文件名及版本属性均显示版本号。
- 本工具不创建桌面快捷方式；不检测或修改桌面内容。
- 常驻部分迁移到原生 C++，通过 Windows 设备到达通知响应插盘，通过注册表事件响应托盘变化；只需下载一个安装 EXE。
- 保留 1.2.16 的当前用户登录启动方式，以及此前固定磁盘盘符识别、客户端正常窗口和权限提升启动修复。Shell/COM 只在短暂的权限启动助手中加载，不增加日常监听的常驻开销。
- 客户端启动失败后约 30 秒重试；用户取消 UAC 后不反复弹窗，重新插盘才再次尝试。
- 托盘改为变化监听，修复图标晚创建、可见设置被重置和任务栏重建后的恢复时机；只写入需要变化的目标记录，并限制刷新频率。
- 修复卸载后重新安装时，“计划任务不存在”被误当作操作失败的问题。
- 卸载后删除旧自动播放恢复记录，避免下次安装恢复错误的历史设置；缺失备份时不擅自改变自动播放设置。
- 及时释放进程、注册表和 COM 资源；移动盘以设备通知触发检查，另有 60 秒兜底；后台进程和任务栏检测每 5 秒一次，只读取进程名称和编号。
- 增加隔离回归检查和本机安装流程验证脚本。代码审阅及测试边界见 [REVIEW.md](REVIEW.md)。

托盘固定依赖 Windows 11 的 `NotifyIconSettings` 设置。图标实际绘制仍由
EdpEDisk 和 Windows 负责；本次已验证设置恢复逻辑，真实客户端插盘显示需在目标电脑确认。

## 从源码构建

需要 Windows 的 .NET Framework C# 编译器，以及 Visual Studio C++ Build Tools（含 Windows SDK）。
使用以下命令自动编译并运行隔离回归检查：

```powershell
.\Build.ps1
```

后台使用静态 C++ 运行库，不要求目标电脑另装 Visual C++ Runtime。管理程序内嵌后台文件，
发布和使用时只需 `EdpEDiskAutoRun-1.2.17.exe`。生成的独立后台 EXE 仅供构建和开发验证。

已有构建的独立回归检查（仅使用临时目录及临时注册表键）：

```powershell
& .\RegressionChecks.exe
Start-Process .\EdpEDiskAutoRun-Watcher-1.2.17.exe -ArgumentList '--self-test' -Wait -PassThru
```

`VerifyLifecycle.ps1` 是开发验证脚本，会操作当前用户的真实安装：取消更新、更新
（仅当测试文件较新）、取消卸载、卸载、重新安装。它会备份原安装文件，测试成功后保留
新版安装；不要在不希望变更安装状态的电脑上运行。卸载后中断可用 `-ResumeReinstall` 继续安装。
若已有 `.verification-backup` 中的旧版备份，`-UpgradeFromPrevious` 可测试旧版到新版的完整更新路径。
该模式使用经 SHA-256 校验的 1.2.16 发布文件。`-RepairInstalled` 可先显式修复当前安装，再测试同版本卸载/重装，适合重新编译同版本后的开发验证。
`-SelfUninstall` 可验证从安装目录内运行管理程序并确认卸载；此时正在运行的管理 EXE 会保留，但启动项、后台和安装状态被移除，再次运行会提示首次安装。
